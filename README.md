# «Батыр Баян» — интерактивті әдеби оқу алаңы

Статикалық HTML/CSS/JavaScript жобасы. Backend, аккаунт немесе аналитика жоқ. Прогресс браузердің `localStorage` қоймасында сақталады.

## Іске қосу

Жоба түбірінде терминал ашыңыз:
```bash
python3 -m http.server 8000
```
Браузерде `http://localhost:8000` ашыңыз. JSON `fetch()` арқылы оқылатындықтан, `index.html` файлын `file://` арқылы тікелей ашпаңыз.

## Поэма мәтінін енгізу

`content/poem.json` файлын ашып, әр бөлімдегі `[ВСТАВИТЬ ТЕКСТ ГЛАВЫ N]` белгісін тексерілген, пайдалануға құқығыңыз бар басылым мәтінімен ауыстырыңыз. JSON жолындағы жаңа жолдар `\n` арқылы жазылады. Шумақ арасын бос жолмен белгілеңіз. Поэманың толық мәтіні жобаға әдейі қосылмаған.

Бөлім үлгісі:
```json
{
  "id": "chapter-6",
  "title": "6-бөлім",
  "text": "Бірінші жол\nЕкінші жол\n\nКелесі шумақ",
  "reflection_kk": "Осы үзіндіге қатысты сұрақ.",
  "reflection_ru": "Вопрос к фрагменту.",
  "footnotes": [
    {"word":"Көнерген сөз","definition_kk":"Қазақша түсіндірме","definition_ru":"Объяснение по-русски"}
  ]
}
```

## Сөздік

`content/glossary.json` ішіндегі `items` массивіне объект қосыңыз:
```json
{"id":"g9","term":"Жаңа сөз","definition_kk":"Қазақша мағынасы","definition_ru":"Русское объяснение","chapter":"chapter-1","verified":true}
```
`verified` тек мұғалім тексергеннен кейін `true` болуы керек.

## Ойындарға дерек қосу

`content/games.json` файлының тиісті массивіне жаңа объект қосыңыз. Әр тапсырмада бірегей `id` болуы керек.

- `match`: `prompt`, `pairs` массиві (`left`, `right`), `explanation`, `chapter`.
- `order`: `items` массиві; әр элементте `id`, `text`, дұрыс ретті білдіретін `order` саны.
- `fill`: `template`, `answer`, `accepted`, `explanation`, `chapter`. Бос орын `___` арқылы белгіленеді. Тек нақты мәтіннен алынған жолды пайдаланыңыз.
- `who`: `quote`, `options`, `answer`, `explanation`, `chapter`. Дәйексөз бен сөйлеушіні тексеріңіз.
- `wordsearch`: `words`, `grid`, `explanation`, `chapter`. Қазіргі үлгі сөздерді көлденең іздейді.
- `flashcards`: `front`, `back`, `chapter`.

Қазіргі ойындарда әр форматқа 1–2 үлгі тапсырма бар. Үлгі және толтырылмаған жауап кілттерін мұғалім тексеріп, нақты дерекпен алмастыруы керек.

## Тест қосу

`content/quizzes.json` файлына тест объектісін қосыңыз. Қолданылатын түрлері: `single` (бір жауап), `multiple` (бірнеше жауап), `truefalse` (дұрыс/бұрыс), `short` (дәл сәйкес келетін жауаптар тізімі).

```json
{
  "id":"q6",
  "type":"single",
  "level":"Талдау",
  "text":"Сұрақ мәтіні",
  "options":["А нұсқасы","Ә нұсқасы","Б нұсқасы"],
  "answer":"Ә нұсқасы",
  "explanation":"Дұрыс жауаптың түсіндірмесі",
  "chapter":"chapter-2",
  "verified":true
}
```
Әр тарауға 5–8 сұрақ, қорытынды тестке 15–20 сұрақ ұстаңыз. Бұл жобаға тек мысал сұрақтар қосылған; жариялау алдында толықтырыңыз. Ашық пікір сұрақтарын дәл жауаппен автоматты бағалау жеткіліксіз — мұғалім рубрикасын пайдаланыңыз. Сұрақтар мен жауап нұсқалары кездейсоқ ретпен беріледі.

## Тіл және контент

Интерфейстің негізгі мәзірі Қаз/Рус ауыстырғышымен аударылады. Оқу контентінің толық орысша аудармасы әлі берілмеген; JSON ішіндегі `*_ru` өрістерін толтырып, статикалық бөлімдерге де аударма қосыңыз.

## Жариялау

GitHub Pages: репозиторийге жүктеңіз → Settings → Pages → Deploy from a branch → `main` және `/ (root)`. Cloudflare Pages/Netlify үшін build командасын бос қалдырып, publish directory ретінде `.` көрсетіңіз.

`index.html` ішіндегі `og:image` — үлгі URL. Нақты 1200×630 HTTPS суретіне ауыстырыңыз. Автор портретін заңды дереккөзден WebP форматында `assets/img/` ішіне қосып, placeholder блогын мағыналы `alt` атрибуты бар `img` элементімен алмастырыңыз.

## Қолжетімділік және құпиялылық

Кодта skip link, фокус индикаторлары, responsive layout, aria-live аймақтары және drag-and-drop-сыз балама басқару бар. WCAG 2.1 AA сәйкестігін жариялау алдында автоматты және қолмен тексеріңіз; шаблон сәйкестікке кепілдік бермейді.

Деректер серверге жіберілмейді. CSV экспорты нәтижелерді жергілікті файл ретінде жүктейді. `localStorage` тазаланса, прогресс жоғалады. Өмірбаян мен тарихи контекстті, дәйексөздерді және жауап кілттерін мұғалім тексеруі қажет.
